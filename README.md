# مدينة النور - لعبة تعليمية تفاعلية عن مصادر الضوء

## 🌟 نظرة عامة

**مدينة النور** هي لعبة تعليمية تفاعلية مصممة لتعليم الطلاب عن مصادر الضوء الطبيعية والاصطناعية. تجمع اللعبة بين التعلم والمتعة من خلال رسومات جميلة وتفاعل مباشر.

## 🎮 مراحل اللعبة

اللعبة تتكون من 6 مشاهد تعليمية متقدمة:

### المشهد 1️⃣ - الاستكشاف (Scene 1: Exploration)
- **الهدف:** التعرف على أنواع مصادر الضوء المختلفة
- **الأنشطة:** النقر على مصادر الضوء المختلفة لاكتشافها
- **المحتوى:** الشمس، النار، المصابيح الكهربائية، الشموع

### المشهد 2️⃣ - الملاحظة (Scene 2: Observation)
- **الهدف:** ملاحظة سلوك الضوء وخصائصه
- **الأنشطة:** اختبار كيفية تفاعل الضوء مع الأشياء المختلفة
- **المحتوى:** انتشار الضوء، الانعكاس، العتمة والنور

### المشهد 3️⃣ - التوليف (Scene 3: Synthesis)
- **الهدف:** فهم الخصائص المشتركة لجميع مصادر الضوء
- **الأنشطة:** اكتشاف بطاقات الخصائص المختلفة
- **الخصائص المكتشفة:**
  - 🔥 الحرارة
  - ⚡ الطاقة
  - 👁️ الرؤية
  - 🎨 اللون
  - → الاتجاه

### المشهد 4️⃣ - التصنيف (Scene 4: Classification)
- **الهدف:** اختبار المعرفة المكتسبة
- **الأنشطة:** تصنيف الأشياء كمصادر ضوء أو عدم كونها
- **النقاط:** يحصل الطالب على نقاط لكل إجابة صحيحة

### المشهد 5️⃣ - التطبيق (Scene 5: Application)
- **الهدف:** تطبيق المعرفة بطريقة عملية
- **الأنشطة:** إضاءة مباني المدينة المظلمة
- **التحدي:** استخدام الفهم الصحيح لمصادر الضوء

### المشهد 6️⃣ - الاحتفال (Scene 6: Celebration)
- **الهدف:** الاحتفال بالنجاح والتعلم
- **المحتوى:** عرض الإنجازات وملخص التعلم
- **الرسومات:** تأثيرات احتفالية وألعاب نارية رقمية

### المكونات الأساسية

#### 1. **GameEngine** (محرك اللعبة)
- إدارة المشاهد والانتقالات بينها
- نظام الأحداث والمدخلات
- إدارة الجزيئات والرسومات
- نظام الرسائل والأزرار

#### 2. **Scene System** (نظام المشاهد)
- كل مشهد يرث من فئة `Scene` الأساسية
- دورة حياة المشهد: `init()` → `update()` → `render()`
- معالجة أحداث النقر الخاصة بكل مشهد

#### 3. **AudioManager** (مدير الصوت)
- تشغيل الأصوات عند الأحداث المهمة
- موسيقى النجاح والخطأ والاكتشاف
- استخدام Web Audio API

#### 4. **GraphicsManager** (مدير الرسومات)
- رسم الشخصيات والعناصر
- تأثيرات الإضاءة والتوهج
- الرسومات المتجهة 2D

## 📊 أهداف التعلم

بعد إكمال اللعبة، يجب أن يتمكن الطالب من:

✅ تحديد وتصنيف مصادر الضوء المختلفة
✅ فهم الفرق بين مصادر الضوء الأولية والثانوية
✅ معرفة الخصائص المشتركة لجميع مصادر الضوء
✅ تطبيق المعرفة في سياقات جديدة
✅ فهم أهمية الضوء في الحياة اليومية

## 🎯 المنهج التعليمي

تتبع اللعبة نموذج التعليم المتدرج:

```
الاستكشاف → الملاحظة → التوليف → التصنيف → التطبيق → الاحتفال
(Explore) → (Observe) → (Synthesize) → (Classify) → (Apply) → (Celebrate)
```

هذا يعكس المراحل الستة لنموذج التعلم البنائي (Constructivist Learning Model).
